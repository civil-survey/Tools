# civil-survey / tools

측량·토목설계 업무용 개인 도구 모음

| 폴더 | 내용 | 상태 |
|---|---|---|
| `dream-lisp/` | CAD 리습 묶음 '드림' + 측량조사 리습 통합 | 준비 중 |
| `cad-map-overlay/` | CAD 도면을 영상지도·일반지도에 올려 보는 도구 (DMAP 참조, 도면맵) | 준비 중 |
| `coordinate-converter/` | TM ↔ 경위도 좌표변환 프로그램 (엑셀시트 대체) | 준비 중 |
| `retaining-wall-check/` | 옹벽 설계검토 도구 (RAD 대체) | 준비 중 |
| `survey-report/` | 측량조사보고서 양식·검토 관련 자료 | 준비 중 |

## 사용 규칙
- 현장 실제 좌표·개인정보가 든 성과 자료는 올리지 않는다 (저장소가 공개라면 특히 주의).
- 각 폴더의 README에 사용법과 변경 내역을 적는다.
